### built

**[Moroccan Legal Assistant](https://github.com/e-1305/Moroccan-Legal-Assistant---RAG-LLM)**
Ask a question about Moroccan law, get an answer drawn only from the official codes, with the page it came from. If the texts don't say, it tells you. My capstone, graded A+.

**[mindly](https://github.com/e-1305/mindly)**
A thirty-second daily check-in for teams. Managers see how the team is doing, never how one person is doing. That rule lives in the code, not in a privacy policy.
<sub>React · TypeScript · AWS Lambda · DynamoDB · Bedrock</sub>
